Numerous built-in functions are available to obtain extensive help
about syntax, errors, commands and functions of a program with help
messages, manual pages and documentation.

Other built-in functions can be used for owner, property, environment
and trace management. All built-in functions are designed to
simplify the handling of powerful and sometimes complex commands.

.Abbreviations

Built-in function names can be abbreviated for interactive use.
See <<CLEP.MAIN.ABBREVIATIONS,abbreviations>> for detailed information
about abbreviation rules and usage recommendations.
